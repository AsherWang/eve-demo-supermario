# 0.0.6 — Windows x64

本版增加 World 1-3、1-4，现可从 1-1 连续游玩到 1-4 城堡结尾。

## 运行

下载 `super-mario-0.0.6-win64.zip`，完整解压后双击根目录的 `SuperMario.exe`。
保留同目录的 `runtime/`、`native/`、`assets/` 和 `scripts/`，不要单独移动 EXE。

- 方向键或 A/D：移动；Z / 空格：跳跃。
- X / 左 Shift：加速、发射火球；下方向键：进入可用竖向管道。
- 向右走入可用侧向管道；R：重新开始。

## 本版内容

- 增加 1-3 地图、红乌龟、飞龟、移动平台和关尾流程，支持切换进入 1-4。
- 增加 1-4 城堡、火棒、库巴、斧头、桥梁坍塌和救出 Toad 的结束流程。
- 修复踩飞龟后的移动小数位置、移动平台和敌人的屏幕边缘裁切、浮动分数残影。
- 修复金币拾取后的画面更新、关尾旗子、HUD 更新时序和 1-3 到 1-4 的加载流程。
- 修复库巴运动方向、张嘴期间移动和斧头身体碰撞导致的提前通关。
- 更新 Windows 窗口标题，保留游戏图标及首帧就绪后显示窗口的启动流程。

## 验证与已知限制

- 1-3 的 2240 帧整关与切关路线通过状态、事件、APU、音频和产物完整性检查。
  2239 帧画面完全一致，第 1419 帧仍有 5 个 HUD 像素差异，严格画面门禁未通过。
- 1-4 的 2400 帧固定路线已验证无死亡通关，斧头触发在第 1863 帧与原版一致；
  玩家位置对齐至第 1985 帧。通关自动行走、库巴垂直运动及部分画面音频时序仍需对齐。
- 固定路线验证不覆盖全部探索路径、形态与死亡重生组合；1-2 也仍有原版对比差异。
  本版为可试玩的迭代版本，不宣称所有关卡已通过严格 1:1 验收。
- 2-1 尚未实现，完成 1-4 后停在当前结束流程，不能继续下一世界。
