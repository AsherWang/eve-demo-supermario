# 0.01 — Windows x64

EVEngine 超级马里奥 1-1 个人学习 / vibe coding 项目的首个发布版本。
本次只提供 Windows x64 游戏包，不包含 ROM、模拟器或测试存档。

## 运行

下载 `super-mario-0.01-win64.zip`，完整解压后双击 `Play.cmd`。
不要仅从压缩包中打开 EXE，也不要改名 `eve.exe` 或移走附带的 DLL。
后续版本已改用无控制台窗口的 `SuperMario.exe` 启动器，建议使用 0.01.1。
需要支持 Vulkan 的显卡和驱动；无需另外安装 EVEngine。

- 方向键或 A/D：移动。
- Z / 空格：跳跃。
- X / 左 Shift：加速、发射火球。
- 下方向键：在可进入的水管上进入地下区域。
- R：重新开始。

## 本版内容

- World 1-1 地图、敌人、道具、地下金币房与旗杆/城堡结算流程。
- 独立 Windows PCM 音频插件与离线原版采集的音乐、音效。
- 修复高层砖块顶出的金币及“200”分数位置。
- 补上顶砖弹起蘑菇/1UP，以及朝远离马里奥方向移动的响应。
- 修复城堡旗子的背景遮挡顺序与 OAM 显示坐标。

## 验证与限制

已通过本地新增自测，以及首个蘑菇、高位碰旗等既有 ROM 对照用例。
开场静止 10 秒的实际游戏提交 PCM 与参考逐样本一致，未检测到欠载或削波。
发布工作流另外重新编译 Win64 插件并运行混音单元测试；不在云端重跑 ROM 对照或 GPU 画面测试。

这仍是开发中的复刻，不宣称所有方面严格 1:1：新增蘑菇顶砖轨迹尚无独立逐帧 ROM 对照；
音频仍是预录片段混音，没有完整实现 NES 声道抢占和非线性混音交互。
