# 0.0.4 — Windows x64

第四个 Windows x64 发布版本，修复地下区域音乐恢复与管道过渡画面。
本次只提供 Windows x64 游戏包，不包含 ROM、模拟器或测试存档。

## 运行

下载 `super-mario-0.0.4-win64.zip`，完整解压后双击根目录的 `SuperMario.exe`。
同目录的 `runtime/`、`native/`、`assets/` 和 `scripts/` 都是运行所需文件，请勿单独移动。

`SuperMario.exe` 是无控制台窗口的 GUI 启动器。引擎输出写入同目录的 `game.log`，
便于排查启动或插件错误。引擎宿主位于 `runtime/eve.exe`，普通玩家无需直接运行。

- 方向键或 A/D：移动。
- Z / 空格：跳跃。
- X / 左 Shift：加速、发射火球。
- 下方向键：在可进入的水管上进入地下区域。
- R：重新开始。

## 本版内容

- 修复进入地下区域和返回地面后背景音乐不恢复的问题；管道过渡期间仍按原版静音。
- 地下和地面区域加载阶段改用原版天空色与黑屏遮罩，不再显示临时出生位置。
- 加载期间隐藏马里奥，消除下管道时的瞬移和人物闪现。
- 增加地下/地面音乐切换与区域过渡画面的回归检查。

## 验证与限制

内置模拟自检通过；`world-1-1-tas` 的帧、状态、事件、APU 写入和音频对照全部通过。
发布工作流会重新编译 Win64 插件和 GUI 启动器、运行混音单元测试，并检查发布包不包含
ROM、存档或日志。下载附件的 SHA-256 用于完整性校验。

游戏仍是开发中的复刻，不宣称所有方面严格 1:1。区域切换边缘仍有少量单帧显示差异，
音频运行时仍使用预录片段混音，尚未完整模拟 NES 声道抢占和非线性混音。
