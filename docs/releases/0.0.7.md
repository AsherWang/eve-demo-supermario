# 0.0.7 — Windows x64

本版修复 World 1-4 的火棒配色、城堡结尾画面和通关后的重新开始操作。

## 运行

下载 `super-mario-0.0.7-win64.zip`，完整解压后运行根目录的 `SuperMario.exe`。
保留同目录的 runtime、native、assets、scripts，不要单独移动 EXE。
方向键/A/D 移动，Z/空格跳跃，X/左 Shift 加速或发射火球，下方向键进入可用管道，R 重新开始。

## 修复内容

- 1-4 火棒改用原版红橙色调色板，不再误用库巴的绿色调色板。
- Toad 使用正确的红白配色、左右镜像、固定高度和精灵前后层次。
- 结尾恢复原版字体、三行感谢文字及布局，去掉混在画面中的开发占位提示。
- 修复马里奥通关后悬在旧位置、自动行走不落地及显示/动画停止更新。
- 修复砍桥、自动行走、感谢画面和最终停留状态按 R 无法重新开始。

## 验证与限制

- 九组模拟回归通过，包含四关重生、三种形态跨关、城堡重开和龟壳/反弹/道具检查。
- 六条实际回放共 7080 帧完成，覆盖死亡、蘑菇、1-1 主线、1-2 路线、1-3 到 1-4 和城堡通关。
- 本轮 1-1、1-2、1-3 所选用例的状态与事件对照通过。1-3 的 2240 帧画面中，
  2239 帧完全一致，第 1419 帧仍有 5 个 HUD 像素差异。
- 1-4 固定路线可无死亡救出 Toad，三种形态结尾回归通过；库巴、桥梁结束和通关结算时序
  仍有原版差异，严格状态和事件门禁仍未通过。
- 固定回放不覆盖任意探索路径。1-1～1-4 目前为可试玩范围，不宣称全关卡严格 1:1 验收完成。
- 2-1 尚未接通，1-4 结束后停留在感谢画面，可按 R 重新开始当前关。
