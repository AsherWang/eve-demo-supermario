# 0.01.1 — Windows x64

修复 `0.01` 双击启动时额外显示控制台窗口的问题。本次只提供 Windows x64 游戏包。
不包含 ROM、模拟器或测试存档。

## 运行

下载 `super-mario-0.01.1-win64.zip`，完整解压后双击根目录的 `SuperMario.exe`。
不要单独移动它；同目录的 `runtime/`、`native/`、`assets/` 和 `scripts/` 都是运行所需文件。

`SuperMario.exe` 是无控制台窗口的 GUI 启动器。引擎输出写入同目录的 `game.log`，
便于排查启动或插件错误。`Play.cmd` 仍可使用，但会短暂显示批处理窗口。
引擎宿主已移到 `runtime/eve.exe`，普通玩家无需直接运行它。

- 方向键或 A/D：移动。
- Z / 空格：跳跃。
- X / 左 Shift：加速、发射火球。
- 下方向键：在可进入的水管上进入地下区域。
- R：重新开始。
