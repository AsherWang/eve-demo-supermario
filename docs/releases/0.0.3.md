# 0.0.3 — Windows x64

第三个 Windows x64 发布版本，汇总前两次发布的游戏修复和无控制台启动改进。
本次只提供 Windows x64 游戏包，不包含 ROM、模拟器或测试存档。

## 运行

下载 `super-mario-0.0.3-win64.zip`，完整解压后双击根目录的 `SuperMario.exe`。
同目录的 `runtime/`、`native/`、`assets/` 和 `scripts/` 都是运行所需文件，请勿单独移动。

`SuperMario.exe` 是无控制台窗口的 GUI 启动器。引擎输出写入同目录的 `game.log`，
便于排查启动或插件错误。引擎宿主位于 `runtime/eve.exe`，普通玩家无需直接运行。

- 方向键或 A/D：移动。
- Z / 空格：跳跃。
- X / 左 Shift：加速、发射火球。
- 下方向键：在可进入的水管上进入地下区域。
- R：重新开始。

## 本版内容

- World 1-1 地图、敌人、道具、地下金币房、旗杆和城堡结算流程。
- 独立 Windows PCM 音频插件及离线原版采集的音乐、音效。
- 修复高层砖块顶出的金币及“200”分数位置。
- 补上顶砖弹起蘑菇/1UP，并朝远离马里奥方向移动的响应。
- 修复城堡旗子的背景遮挡顺序与显示坐标。
- 使用 GUI 启动器，双击启动时不再显示额外控制台窗口。

## 验证与限制

发布工作流会重新编译 Win64 插件和 GUI 启动器、运行混音单元测试，并检查启动器的
GUI 子系统与 x64 架构。发布包会检查不包含 ROM、存档或日志；下载附件的 SHA-256
用于完整性校验。

游戏仍是开发中的复刻，不宣称所有方面严格 1:1：部分交互尚无独立逐帧 ROM 对照，
音频运行时仍是预录片段混音，未完整模拟 NES 声道抢占和非线性混音。
非官方、非商业学习项目，与 Nintendo 无隶属或背书关系。
