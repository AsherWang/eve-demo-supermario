# 0.0.5 — Windows x64

本版增加 World 1-2，并汇总关卡碰撞、电梯、死亡重生、敌人和音频修复。
只提供 Windows x64 游戏包，不包含 ROM、模拟器或测试存档。

## 运行

下载 `super-mario-0.0.5-win64.zip`，完整解压后双击根目录的 `SuperMario.exe`。
请保留同目录的 `runtime/`、`native/`、`assets/` 和 `scripts/`，不要单独移动 EXE。

- 方向键或 A/D：移动。
- Z / 空格：跳跃。
- X / 左 Shift：加速、发射火球。
- 下方向键：进入可用的竖向管道；向右走入可用的侧向管道。
- R：重新开始。

## 本版内容

- 增加 1-2 地下区域、奖励房间、管道返回、出口与电梯。
- 修复贴墙悬空站立、顶砖后卡在墙中间，以及侧向管口无法进入的问题。
- 修复电梯上的行走动画和玩家随电梯循环传送到屏幕另一端的问题。
- 修复 1-2 死亡后的中途检查点，下一命恢复为小马里奥；修复 1-1 重生后背景音乐丢失。
- 修复乌龟踩踏后连续接触、缩壳动画、龟壳击中敌人后直接消失等问题。
- 修复蘑菇跨过被打碎的相邻砖块空隙、地下敌人卡管道及食人花越界。
- 修正小马里奥吃花的成长顺序，移除 1-2 出口错误生成的两个栗宝宝。
- 修复结算计时音效与 HUD，并在首帧内容就绪后显示窗口，减少启动白屏。
- 补充全部 32 关的开发路线和整关验收要求，以及专项回归与原版证据采集工具。
